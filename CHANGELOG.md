# Changelog

All notable changes follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-14
### Added
- Skills: `pull-prospector` (orchestrator), `pull-offer`, `pull-find`, `pull-draft`, `pull-learn`.
- PULL scoring rubric with Evidenced/Inferred/Absent levels, Lacking tiers (L1–L3), a fit check and a gate.
- Buyer and champion modes, with a path-to-buyer check and a champion kit.
- Dossier = information pack format; workspace layout; CRM-agnostic notes/tags sync; CSV fallback.
- Guardrails: draft-only, public professional data only, honest outreach, CRM write approval.
- Release checklist and "report a bad call" issue template.
